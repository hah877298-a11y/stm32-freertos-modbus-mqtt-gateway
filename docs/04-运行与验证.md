# 运行与验证

## 1. 验证环境

| 项 | 内容 |
|---|---|
| 固件 | 本仓库 `firmware/`，Keil MDK 编译，0 Error |
| 从站 | `tools/modbus_slave_sim.py`（PC 上模拟从站 1） |
| 云端 | 公共 MQTT Broker `broker.emqx.io:1883` |
| 监视 | 串口助手（115200）+ `tools/mqtt_dashboard.html` |

## 2. 上电

1. 开发板只接调试 USB 线，确认串口能收到启动日志。
2. 复位，确认自检项目全部出现（见 `01-硬件与接线.md` 第 4 节）。
3. 接好 Modbus 那路 USB-TTL，确认 `mb ok` 开始周期性出现。

## 3. Modbus 通信

PC 侧：

```bash
pip install pyserial
python tools/modbus_slave_sim.py COM9 --temp 25.0 --hum 50.0
```

设备侧应出现：

```text
mb ok t=25.0 h=50.0 st=1
```

运行中在模拟器里输入 `t 30.5`，设备侧下一次轮询就会读到新值。

## 4. 本地报警闭环

1. 模拟器输入 `t 30.5`。
2. 设备侧 5 s 内出现 `alarm=1`，LED1 点亮。
3. 输入 `t 25.0`，`alarm` 回到 0，LED1 熄灭。

整个过程不依赖网络：把 ESP-01S 拔掉，报警灯依然按温度动作。

## 5. 云端正向验证

1. ESP-01S 上电，串口依次出现 `esp connecting...`、`AT+CWJAP` 返回的 AP 信息、`CONNECT`、`OK`。
2. 出现 `mqtt connack ... 20 02 00 00`，随后 `esp online`。
3. 每 5 s 出现一条 `pub: {...}`，浏览器面板同步显示数值曲线。

## 6. 云端反向验证

在面板上点「LED 常亮」，设备侧串口出现命令报文，LED0 从闪烁变为常亮；
点「恢复闪烁」，LED0 回到 500 ms 心跳。

也可以直接用任何 MQTT 客户端向 `stm32/gw01/cmd` 发布 `{"led":1}`。

## 7. 断线自恢复

1. 断开 ESP-01S 的电源 10 s 再恢复。
2. 设备侧应出现 `net lost, reconnect`，然后重新走一遍联网流程，最后恢复 `pub`。
3. 换一种方式：把路由器关掉再开，同样应自动恢复，不需要复位单片机。

## 8. 验收清单

- [ ] 上电自检项目全部正常
- [ ] `mb ok` 周期约 3 s 持续出现
- [ ] 每 2 s 一条 `can ok id=123 ...`，首字节递增
- [ ] 串口每 5 s 一条 `gw ... heap=... stack=...`，栈水位不持续下降
- [ ] 温度过 30.0 ℃ 时 `alarm=1` 且 LED1 点亮
- [ ] MQTT 每 5 s 一条 JSON，字段与本地读数一致
- [ ] 远程 `{"led":1}` / `{"led":0}` 生效
- [ ] 拔掉 ESP-01S 后本地采集与报警不受影响

## 9. 常见现象对照

| 现象 | 可能原因 | 处理 |
|---|---|---|
| `mb fail -1` | 寄存器数量参数超出 1..16 | 检查 `modbus_read_regs()` 调用参数 |
| `mb fail -2` | USART3 发送失败 | 串口是否被占用、引脚是否接对 |
| `mb fail -3` | 接收超时（最常见） | 从站是否上电、A/B 是否接反、波特率与从站地址 |
| `mb fail -4` | 从站地址不匹配 | 模拟器与固件里的从站号要一致 |
| `mb fail -5` | 功能码或字节数不对 | 从站返回的不是 0x03 |
| `mb fail -6` | CRC 校验错 | 线太长、干扰、波特率偏差 |
| `esp[0] 0 bytes` | ESP-01S 完全无响应 | 共地、EN 接 3.3 V、供电是否够 |
| 反复 `net lost, reconnect` | Wi-Fi 信号弱或 Broker 拒绝 | 看 `AT+CWJAP` 返回的 RSSI，确认主题没被别的设备抢占 |
| 温度显示 `--` 或 0.0 | DS18B20 读失败 | 上拉电阻、DQ 接线；程序会沿用上次有效值 |
| LCD 花屏或死机 | 任务栈不足 | 加大 `LCD_TASK_STACK`，看栈水位打印 |
| `xTaskCreate` 失败 / 堆报警 | `configTOTAL_HEAP_SIZE` 不够 | 减小任务栈或加大堆 |

## 10. 复现边界

本仓库验证的是「一个从站 + 一个 ESP-01S + 一块开发板」的最小闭环，
没有做多从站、断网缓存、时间同步和 TLS。压力测试和高低温长跑也没有做，
作为学习项目足够，作为产品还差得远。
